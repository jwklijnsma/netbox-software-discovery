# NetBox Software Discovery

NetBox 4.5.x software inventory plugin and host discovery agent.

The initial v0.1.0 source distribution is available in `releases/netbox-software-discovery-0.1.0.zip`. Extract it to obtain the complete project tree, including the NetBox plugin, discovery agent, tests, Docker deployment examples, systemd unit and documentation.

See the extracted project's `README.md` and `COMPATIBILITY.md` for installation and compatibility notes.
